# Brand assets

The application icon depicts a monitor outline and a lime brightness curve on a
dark rounded-square background.

- `app.ico` — multi-size Windows executable and shortcut icon
- `app-logo.png` — trimmed raster logo for documentation
- `logo-source.png` — selected high-resolution source artwork

These original project assets are distributed under the repository's MIT
license. They are not copied from another monitor-control project.
