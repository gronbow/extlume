# 外接显示器亮度工具 GitHub 发布规划

> 状态：`v0.2.0-beta.1` 已作为公开 Pre-release 发布
> 日期：2026-07-26
> 正式产品名：ExtLume
> 目标首发：`v0.2.0-beta.1`

## 1. 发布定位

以公开 GitHub 仓库发布一个轻量、离线、无需管理员权限的 Windows 托盘应用，解决 Windows 只为笔记本内置屏提供亮度滑块、外接显示器 OSD 又不可用的问题。

首次发布采用 Beta，不宣称已经覆盖所有硬件。对外准确表述为：

- 能安全识别活动物理外接屏时提供亮度滑块；
- DDC/CI 可用时调节真实背光；
- DDC/CI 不可用、且外接屏桌面源可安全隔离时，明确回退为软件调暗；
- 内置屏、虚拟屏和无法安全分类的目标不控制。
- 外接屏与内置屏共用复制桌面源时禁止软件遮罩；硬件不可用则提示切换到“扩展”。

“普适”是上述双层能力，而不是对所有显示器承诺硬件背光控制。

## 3. 安全红线

- 只允许亮度 VCP `0x10`；
- 不提供任意 VCP、恢复出厂或电源指令；
- 不静默选择第一台显示器；
- 每次写入前重新枚举精确目标；
- 写后回读验证；
- 所有物理显示器句柄必须释放；
- 内置、虚拟和未知单屏不进入控制；
- 内置屏参与复制时禁止软件遮罩；
- 软件遮罩必须可点击穿透、不能全黑、退出即移除；
- 不联网、不遥测、不提权；
- 不保存原始设备路径和 EDID 序列号。

## 5. GitHub 仓库治理

- 启用 Issues、Discussions、Private vulnerability reporting；
- 保护 `main`，要求 CI 通过后合并；
- 禁止强推和删除默认分支；
- 启用 Dependabot、Secret scanning、Push protection；
- Release 工作流只创建 Draft，人工核对后发布；
- 兼容性问题使用专用模板，禁止收集原始序列号；
- 安全问题不进入公开 Issue。

## 6. CI 与发布流程

### Pull request / push

1. 干净环境构建；
2. 运行全部自动化与实时只读测试；
3. 检查硬编码专用型号、任意 VCP、秘密和私有路径；
4. 上传未签名测试构件供审阅。

### 标签发布

1. 从标签重新构建；
2. 运行测试；
3. 生成便携 ZIP；
4. 生成当前用户安装包；
5. 计算 SHA-256；
6. 生成构建证明；
7. 创建 Draft Release；
8. 人工下载复验、扫描和核对版本；
9. 最后手动发布。

## 7. 发布前验证矩阵

- 自动化测试全部通过；
- 当前机器 DisplayConfig 只读探针通过；
- 原 H25T7-3 真实硬件执行读取、25% 写入与回读；
- 中英文与 100%/150%/200% 缩放无截字；
- 单实例、托盘、开机启动、热插拔和恢复通过；
- DDC 不可用且桌面源可隔离时，软件调暗可用且标注准确；
- 复制模式不重复枚举、不误调；内置屏共享桌面源时软件遮罩被阻止；
- 安装、覆盖安装、卸载、便携包均通过；
- 校验文件与构件一致；
- README 不包含绝对本机路径、隐私数据或过度承诺。
