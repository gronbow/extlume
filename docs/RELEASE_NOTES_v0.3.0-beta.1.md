# ExtLume v0.3.0-beta.1

This beta iteration redesigns ExtLume's interface while preserving the
external-display safety model and DDC/CI behavior of v0.2.0-beta.1.

## Highlights

- New iOS-inspired glass interface with graphite depth and the icon's lime
  accent.
- Reworked header, monitor cards, control-mode badges, status bar, empty
  states, and dark scrollbars.
- New custom brightness slider with mouse drag, mouse wheel, arrow keys,
  Home/End, and Page Up/Page Down support.
- Slider accessibility metadata and visible keyboard focus.
- Responsive Chinese and English layouts validated at 100%, 150%, and 200%
  scaling.
- Safe Windows title-bar dark-mode, rounded-corner, and backdrop requests with
  automatic fallback on unsupported builds.

## Preserved safety behavior

- Built-in and virtual displays remain excluded.
- Hardware brightness writes still use verified read/write/readback flows.
- Direct VCP access remains limited to brightness code `0x10`.
- Software dimming remains explicitly labeled and blocked for unsafe internal
  clone topologies.
- The app still makes no network requests and requires no administrator
  privileges.

## Beta limits

Real hardware validation covers one `H25T7-3` HDMI monitor through the Windows
high-level hardware-brightness API. Other monitor, dock, KVM, DisplayLink, MST,
and direct-VCP combinations remain community beta-matrix items.
